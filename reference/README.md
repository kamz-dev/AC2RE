# reference/: material from earlier projects

`ac1/` holds the AC1 movement project's tools as they were: the lab mod (`ac1/livelab/`, C, with its Python tools)
and the static readers (`ac1/re_tools/`). **Every address, offset and data format in them is AC1's** (Steam v1.02,
`AssassinsCreed_Dx9.exe`). Read them for technique and structure, port what you need into `livelab/` or
`RE/tools/` with AC2 values, and don't run them against AC2.

Don't edit files here, except to fix something that misleads.
